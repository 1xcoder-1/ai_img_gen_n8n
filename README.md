# AI Img Gen

A simple, automated n8n workflow that researches trending topics, writes an engaging post, creates a custom visual prompt, generates an AI image, and sends the final content directly to your email.

---

## 📌 Workflow Overview

This workflow automates the end-to-end content creation process:
1. **Trigger Form**: Takes your post topic, target audience, and email.
2. **Research & Drafting**: Performs live web search to collect recent insights and crafts a tailored post.
3. **Prompt Creation**: Analyzes the written post and designs a marketing-style image prompt.
4. **AI Image Generation**: Generates a high-resolution 1024x1024 graphic matching the post topic.
5. **Delivery**: Converts the generated image into a file and delivers the post and image via email.

---

## ⚙️ How It Works (Step-by-Step)

```
[Form Trigger] 
       │
       ▼
[Content Post Agent] ── (Tavily Search + LLM)
       │
       ▼
[Image Prompt Agent]
       │
       ▼
[AI Img Gen (HTTP)]
       │
       ▼
[Convert to Binary]
       │
       ▼
[Send Post (Gmail)]
```

### 1. Form Submission
- **Node**: `On form submission`
- Collects:
  - **Email**: Recipient address for the finished post
  - **Topic of Post**: The subject to write about
  - **Target Audience**: Who the post is written for

### 2. Content Generation
- **Node**: `LinkedIn Post Agent`
- Connected to:
  - **Web Search Tool** (`Tavily`): Gathers up-to-date facts and data.
  - **Chat Model** (`GPT_4.1` / OpenRouter): Writes an insightful, structured post with hooks, sources, hashtags, and a call-to-action.

### 3. Visual Prompt Generation
- **Node**: `Image Prompt Agent`
- Translates the generated post into a concise, creative visual prompt for an AI image generator.

### 4. AI Img Gen
- **Node**: `Generate Image`
- Sends the image prompt to an image generation API endpoint and returns the generated image.

### 5. Binary Conversion & Delivery
- **Convert to Binary**: Converts the image payload into a usable binary attachment.
- **Send Post (Gmail)**: Sends an email to the user with the written post and attached AI image.
- *(Optional)*: An integrated LinkedIn node can be enabled to publish directly.

---

## 🚀 Setup & Credentials

Before running the workflow, configure these credentials in n8n:

1. **Language Model Provider (OpenRouter)**: For content and prompt drafting.
2. **Search Tool (Tavily)**: HTTP Header Auth with your Tavily API key for live research.
3. **Image Generation API**: Add your API key in the `Authorization` header of the `Generate Image` node.
4. **Email / Gmail**: OAuth2 connection to send out the finished post and image.

---

## 🧪 Testing the Workflow

1. Open the workflow in n8n.
2. Use the test trigger or open the form URL generated by the **On form submission** node.
3. Enter your email, topic, and target audience.
4. Check your inbox for the complete post and generated image!
